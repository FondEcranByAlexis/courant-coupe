# Courant Coupé

Prototype FBA Games en 3D à la première personne. Dans la première mission, un boulanger appelle à l'aide après une coupure déclenchée par son four.

## Jouer

Ouvrir `dist/index.html` dans un navigateur récent. Le jeu fonctionne hors ligne et sans installation. Pour l'héberger, servir le dossier `dist/` avec un hébergeur statique.

- Clavier : ZQSD ou WASD pour marcher. Flèches gauche/droite ou glissement à la souris pour regarder. E pour interagir.
- Écran tactile : joystick pour marcher, glissement dans la scène pour regarder, bouton d'action pour interagir.
- La flèche et la distance indiquent le prochain objectif. Le menu « ? » affiche les commandes.

Les relevés et réparations font partie d'une simulation de jeu.
